# TASK DO

Aplikasi web pencatat tugas (To Do List) untuk mahasiswa: catat tugas beserta deadline, tandai selesai, lihat statistik 7 hari terakhir, dan lengkapi profil.

## Cara menjalankan
1. Clone repositori: https://github.com/azizabrisam00/ppv-project-akhir-5125500040
2. Jalankan server lokal dari folder proyek: `python -m http.server 5500`
3. Buka http://127.0.0.1:5500/

## Fitur MVP dan status
| Fitur | Status |
|---|---|
| Catat tugas + deskripsi + deadline | Selesai |
| Tandai selesai dan hapus tugas (dengan konfirmasi) | Selesai |
| Statistik persentase dan diagram batang 7 hari terakhir | Selesai |
| Profil pengguna (data diri dan foto) | Selesai |
| Penyimpanan aman (tahan data rusak dan penyimpanan diblokir) | Selesai (Sprint 4) |
